# Dados locais

Esta pasta armazena o banco SQLite local e os tokens OAuth individuais por perfil durante a execucao.

Os arquivos de dados reais nao sao distribuidos. O banco pode conter nomes, e-mails, telefones, curriculos referenciados e historico de candidaturas; mantenha-o fora do controle de versao.

Os scripts de manutencao locais foram excluidos do versionamento por enquanto, pois alguns contêm contatos e rotinas de envio especificos do ambiente pessoal. Antes de publica-los, remova dados pessoais, caminhos absolutos e destinatarios codificados e adicione testes.

A criacao automatizada de um banco novo e o cadastro inicial de perfil ainda precisam ser implementados para uma instalacao limpa.
