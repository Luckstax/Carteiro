Configuracao local do Carteiro

Coloque aqui apenas configuracoes locais que nao contenham segredos, se necessario.

As credenciais OAuth devem ficar no arquivo credentials.json na raiz local do projeto; os tokens ficam em dados/tokens/.
Esses arquivos sao ignorados pelo Git e nunca devem ser publicados.

Nao coloque curriculos, bancos de dados ou dados pessoais nesta pasta para publicacao.
